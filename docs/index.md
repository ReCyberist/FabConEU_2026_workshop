# Azure SQL or Fabric SQL: Deploying Infrastructure and Databases as Code

**FabCon Europe 2026 · Barcelona · Full-day workshop**
Presented by **Jess Pomfret** & **Rob Sewell**

---

Managing Azure SQL or Fabric SQL by hand doesn't scale. In this workshop you'll deploy
both your infrastructure and your database schemas **as code**, and build real CI/CD
pipelines that provision resources and ship database changes automatically — version
controlled, repeatable, and ready for production.

**Hands-on, practical, and no clicking required.**

## What you'll do
- Provision **Azure SQL** and **Fabric SQL** as code (Terraform), side by side.
- Define your database schema as code with **SQL projects** (`.sqlproj` / DACPAC).
- Wire it all into **CI/CD pipelines** (GitHub Actions) that deploy automatically.

!!! note "How this site works"
    The **steps** you read here on the site. The **code** you download and run — each
    module links to a downloadable bundle. Everything you deploy, you deploy from code.
