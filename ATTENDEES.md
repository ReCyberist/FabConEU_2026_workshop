# Attendees

A guest book, and a safe place to make your first change.

During the **source control** section of the workshop you will add a line to this file in your own
fork, open a pull request, and watch the checks run. Nothing here is used by any pipeline or any
piece of code — the file exists purely so that your first pull request changes something real
without being able to break anything.

Add yourself to the bottom of the list, in this shape:

```markdown
- **Your name** — City, Country — the thing you would most like to stop doing by hand
```
